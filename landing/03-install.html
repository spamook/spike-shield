Install

Not installed
Add Spike Shield to this app. In index.html, inside <head> and before any other script, add <script src="https://cdn.spikeshield.app/shield.js" data-site="idea-roaster" data-api="https://api.spikeshield.app"></script> without async or defer. In src/main.tsx, wait for window.SpikeShield?.ready (use Promise.resolve() if it is undefined) before calling createRoot().render.
